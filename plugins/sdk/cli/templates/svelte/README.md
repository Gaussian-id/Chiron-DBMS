## Develop

Install dependencies and run the browser development host:

```bash
npm install
chiron-horizon-plugin dev --path . --port 5190
```

Commit the generated `package-lock.json`. Release CI uses `npm ci` with the lockfile and caches npm downloads; it does not resolve a new dependency tree for every release.

The UI is compiled from `src/` into `ui/`. The generated `window.chiron_horizonPlugin` bridge exposes Chiron Horizon context, locale, theme and backend methods to the Svelte workbench. Use the real Chiron Horizon host for final integration testing.

Build an unsigned universal candidate with `npm run build && chiron-horizon-plugin package .`.

## Release

Build candidates with `chiron-horizon-plugin package .`, then publish them through your own GitHub release or custom repository. Sign packages with your repository key before distributing them to other users. An official Horizon plugin catalog and reusable publishing workflow are not configured in this release.

Do not submit ordinary plugin source to `Gaussian-id/Chiron-DBMS`; that repository accepts plugin host, SDK, CLI, schema, documentation, and official-example changes.
