## Develop

Install dependencies and run the browser development host:

```bash
npm install
gauss-horizon-plugin dev --path . --port 5190
```

The UI is compiled from `src/` into `ui/`. The generated `window.gaussHorizonPlugin` bridge exposes Gauss Horizon context, locale, theme and backend methods to the Svelte workbench. Use the real Gauss Horizon host for final integration testing.

Build an unsigned universal candidate with `gauss-horizon-plugin package .`.

## Release

Publish the unsigned candidate for review. If this repository is registered with `autoUpdate: true`, Gauss Horizon Store automatically creates or updates a candidate PR; otherwise, submit one candidate PR to `Gaussian-id/Gauss-DBM-store:main` with the release and artifact metadata. A submission Issue is not required. Gauss Horizon Store signs approved official releases and updates the same PR with the installable package. Do not submit ordinary plugin source to `Gaussian-id/Gauss-Horizon`; that repository accepts plugin host, SDK, CLI, schema, documentation, and official-example changes.
