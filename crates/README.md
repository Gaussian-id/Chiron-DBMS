# Crates

Rust crates for Gauss Horizon live here.

## Directories

- `gauss-horizon-core/` - shared database core, drivers, schema/query logic, import/export, transfer, and plugin support.
- `gauss-horizon-web/` - the Docker/web backend service binary published as `gauss-horizon-web`.

The workspace root is defined in the repository-level `Cargo.toml`.
