## Data and Backup

<Accordions>
  <Accordion title="Where is my connection configuration stored?">
    Chiron Horizon Desktop stores connections, saved credentials, SSH tunnel profiles, query history, and app settings in a single SQLite database file `chiron-horizon.db` inside the Chiron Horizon data directory:

    - **Windows (installer):** `C:\Users\<user>\AppData\Roaming\id.chiron.horizon\chiron-horizon.db`
    - **Windows (portable ZIP):** `<Chiron Horizon.exe folder>\data\chiron-horizon.db`
    - **macOS:** `~/Library/Application Support/id.chiron.horizon/chiron-horizon.db`
    - **Linux:** `~/.local/share/id.chiron.horizon/chiron-horizon.db`

    SSH host keys are kept in `known_hosts` in the same directory, so Chiron Horizon never touches `~/.ssh`. Depending on write activity, `chiron-horizon.db-wal` and `chiron-horizon.db-shm` checkpoint files may sit next to the database.

    Older Chiron Horizon releases kept connections in `connections.json` and `secrets.json`. These files are migrated into `chiron-horizon.db` automatically on startup and the originals are renamed to `*.bak`.

    To move connections to another machine, use encrypted [Config Export/Import](/en/docs/config-export) instead of copying files. For a manual backup, quit Chiron Horizon first, then copy the whole data directory, or at least `chiron-horizon.db` together with the `-wal` and `-shm` files.
  </Accordion>
  <Accordion title="Can I keep the data next to the executable, or use a custom data directory?">
    Yes. There are two supported ways:

    - **Windows portable ZIP:** the `CHIRON_HORIZON_<version>_<arch>-portable.zip` from the release page ships with a `portable.chiron-horizon` marker file. Extract it anywhere and run it; all data is stored in the `data` folder beside `Chiron Horizon.exe`. On first launch, if the portable folder is still empty and older data exists in `AppData`, it is imported automatically once.
    - **`CHIRON_HORIZON_DATA_DIR` environment variable:** works on every platform and for both installer and portable builds, and takes the highest priority. Point it at any folder. The new directory starts empty, so migrate with Config Export/Import, or copy `chiron-horizon.db` while Chiron Horizon is not running.

    The `portable.chiron-horizon` marker only works on Windows, and it is ignored when `uninstall.exe` sits next to the executable (installed builds). There is no in-app setting for the data directory.
  </Accordion>
</Accordions>
